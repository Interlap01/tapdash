# TapDash

TapDash is a tiny native iOS hypercasual game built with SpriteKit: shapes fall, you tap them before they hit the bottom, and three misses end the run.

It exists as the end-to-end test app for the [Builder](https://github.com/MobAI-App/ios-builder) CLI — remote GitHub Actions builds, signing without a Mac, and TestFlight upload.

The Xcode project is generated from `project.yml` with [XcodeGen](https://github.com/yonaskolb/XcodeGen); run `xcodegen generate` before building locally.
